# Séries et progression Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter une collection Séries TMDB avec suivi local par saison et épisode.

**Architecture:** Une table d'épisodes liée au média persiste la progression. FastAPI expose la création TV, la lecture de progression et la bascule d'un épisode. React filtre les médias par type et rend une grille/fiches adaptées avec barres calculées.

**Tech Stack:** Python, SQLite, FastAPI, React, Vite, pytest.

## Global Constraints

- Les séries utilisent `Media.type == "Série"`.
- Une progression complète calcule le statut `Terminée`; une progression partielle calcule `En cours`; zéro épisode vu calcule `À regarder`.
- La barre générale et les barres de saisons affichent vus, total et pourcentage.
